🚀 INICIO RÁPIDO EN 3 PASOS
═══════════════════════════════════════════════════════════════════════════════

PASO 1️⃣ - ABRE LA PÁGINA
────────────────────────────────────────────────────────────────────────────────
1. Asegúrate de que logo.jpg está en la misma carpeta que index.html
2. Haz doble clic en index.html
3. Se abrirá en tu navegador predeterminado
4. ¡Verás tu landing page completa!

PASO 2️⃣ - PERSONALIZA EL CONTENIDO
────────────────────────────────────────────────────────────────────────────────
1. Abre index.html con un editor de texto (Notepad, VSCode, etc.)
2. Busca y reemplaza:
   
   Búsqueda: "LULOS"
   Reemplazar con: "TU NOMBRE DE NEGOCIO"
   
   Búsqueda: "@banderillaslulos"
   Reemplazar con: "@tu_usuario_instagram"
   
   Búsqueda: "info@lulosbanderillas.com"
   Reemplazar con: "tu_email@ejemplo.com"

3. Guarda el archivo (Ctrl+S)
4. Recarga la página en el navegador (F5)

PASO 3️⃣ - DESPLIEGA EN INTERNET (Opcional)
────────────────────────────────────────────────────────────────────────────────
OPCIÓN A - Vercel (Recomendado):
  1. Ve a vercel.com
  2. Haz clic en "Sign Up"
  3. Sube tu carpeta
  4. ¡Listo en segundos!

OPCIÓN B - Netlify:
  1. Ve a netlify.com
  2. Arrastra tu carpeta
  3. ¡Listo en segundos!

OPCIÓN C - Tu propio hosting:
  1. Sube los archivos con FTP
  2. Apunta tu dominio
  3. ¡Listo!

🎨 styles.css (LOS COLORES Y DISEÑO)
──────────────────────────────────────────────────────────────────────────────
┌─────────────────────────────────────────────────────────────────────────┐
│ ¿QUÉ ES?    Los estilos, colores y animaciones                         │
│ ¿PARA QUÉ?  Hace que la página se vea bonita                          │
│ ¿CÓMO EDITAR? Abre con editor de texto                                 │
│ ¿QUÉ CAMBIAR? Colores, tamaños, animaciones, espacios                  │
└─────────────────────────────────────────────────────────────────────────┘

VARIABLES PRINCIPALES (En las primeras líneas):

:root {
    --primary-yellow: #FFD700;      ← Color amarillo
    --primary-red: #E63946;         ← Color rojo
    --primary-black: #1A1A1A;       ← Color negro
    --primary-cream: #F7F3E9;       ← Color crema
    --accent-orange: #FF8C42;       ← Color naranja
}

CAMBIAR COLORES ES FÁCIL:
1. Abre styles.css
2. Busca :root {
3. Cambia los valores de color
4. Guarda (Ctrl+S)
5. Recarga la página (F5)

🆘 PROBLEMAS COMUNES Y SOLUCIONES
═══════════════════════════════════════════════════════════════════════════════

PROBLEMA: La página no se carga
SOLUCIÓN: 
  1. Verifica que index.html está en la carpeta
  2. Intenta abrirlo con clic derecho → Abrir con → Navegador
  3. Comprueba la ruta completa

PROBLEMA: Las imágenes no se ven
SOLUCIÓN:
  1. Asegúrate que logo.jpg está en la misma carpeta
  2. Verifica que el nombre sea exacto (mayúsculas/minúsculas importan)
  3. Comprueba que el archivo no esté dañado

PROBLEMA: Los estilos no se cargan
SOLUCIÓN:
  1. Verifica que styles.css está en la misma carpeta
  2. Borra el caché del navegador (Ctrl+Shift+Del)
  3. Abre en navegador privado

PROBLEMA: El menú móvil no funciona
SOLUCIÓN:
  1. Asegúrate que script.js está en la carpeta
  2. Abre consola (F12) para ver errores
  3. Prueba en otro navegador

PROBLEMA: No puedo cambiar los colores
SOLUCIÓN:
  1. Edita styles.css
  2. Busca :root {
  3. Cambia los valores HEX
  4. Guarda y recarga el navegador
