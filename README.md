## 🚀 Cómo Usar

### Opción 1: Abrir localmente
1. Descarga todos los archivos en una carpeta
2. Asegúrate de que `logo.jpg` esté en la misma carpeta
3. Abre `index.html` en tu navegador
4. ¡Disfruta!

### Opción 2: Servidor local (Recomendado)
```bash
# Si tienes Python 3
python -m http.server 8000

# Si tienes Python 2
python -m SimpleHTTPServer 8000

# Si tienes Node.js
npx http-server
```

Luego abre `http://localhost:8000` en tu navegador.

## 🎯 Personalización

### Cambiar Colores
Edita las variables CSS en `styles.css`:
```css
:root {
    --primary-yellow: #FFD700;
    --primary-red: #E63946;
    --primary-black: #1A1A1A;
    --primary-cream: #F7F3E9;
    --accent-orange: #FF8C42;
}
```

### Cambiar Contenido
- **Títulos y texto**: Edita directamente en `index.html`
- **Menú de productos**: Modifica las tarjetas en la sección menu
- **Logo**: Reemplaza `logo.jpg` con tu imagen (mantén el mismo nombre)

### Agregar Enlaces
- **Instagram**: Cambia la URL en los links de Instagram
- **Email**: Actualiza el email en la sección de contacto
- **Ubicación**: Personaliza según tu dirección
